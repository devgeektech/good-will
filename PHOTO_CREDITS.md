# Media provenance

## Client / Goodwill India supplied media

The build uses supplied Goodwill India imagery and video for clothing, blanket outreach, computers, bicycles, school meals, group weddings, laundry, sewing, groceries, school materials, Kanyaratna / Rukwat, toys, hosts, film collaborators, the Guinness certificate, and Goodwill film footage.

Where the same source asset existed in both JPEG and WebP, the site prefers the optimized local WebP version for delivery.

## Journey visuals

- Pune filming: client-supplied Goodwill India programme photography.
- Agra: local Taj Mahal image already supplied in the project assets.
- Jaipur: client-supplied Hawa Mahal image stored locally.
- Mumbai: local editorial Gateway of India illustration created specifically for this microsite so the production package does not hotlink an external image.
- Brahma Kumaris retreat: local editorial architectural illustration of Jagdamba Bhawan, Pisoli, Pune, created for the itinerary treatment. Replace this file with a client-approved campus photograph at the same path if one is supplied later.
- Return: local editorial flight illustration created for the itinerary.

## External links

No Goodwill India photography is hotlinked from the public Goodwill website. The only intentional user-facing external destination in the current build is Anagha Deshmukh's Calendly invitation link. A crowdfunding link is rendered only after `NEXT_PUBLIC_CROWDFUNDING_URL` is configured.
